Helper functions for MatLab.

This folder ([+itom/](.)) has a leading `+` in its name.
It tells MatLab to add this folder in the searching path,
so that you can all the functions within.

Example project folder structure:
```
matlab_project1/
|- main.m
|- +lib1/
|  |- fn1.m
`- +lib2/
   |- fn2.m
```
